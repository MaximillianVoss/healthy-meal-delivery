# План развёртывания

Первое развёртывание выполняется на тестовом стенде с .NET10 и PostgreSQL18 после добавления прикладного решения. Требуются пользователь БД с минимальными правами, миграции после резервной копии, HTTPS, переменные среды и проверка восстановления. Рабочие контейнеры и команды запуска будут добавлены вместе с приложением. Действующих внешних ресурсов текущая версия не создаёт.
